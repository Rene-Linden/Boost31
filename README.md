# Boost31 website

One-page website voor Boost31 (Organisatie & Groei), een activiteit van Soundboard BV.

Gehost via GitHub Pages. Testlink tot het eigen domein gekoppeld is.

## Nog te doen
- Logo (PNG/SVG) plaatsen rechtsboven
- Contactgegevens invullen (e-mail, telefoon, LinkedIn)
- `noindex` verwijderen zodra de site op het eigen domein live gaat
- Eigen domein koppelen: bestand `CNAME` toevoegen + DNS aanpassen
